## Common Issues:

**Chat still disabled?**
- Browser cache issue: Hard refresh (Ctrl+F5)
- Or: WebSocket not connected - check debug page

**Customer can't create?**
- Make sure you're logged in as CUSTOMER role
- Check by going to debug page to see token role

**No notifications?**
- Must create a NEW ticket to trigger
- Notifications only sent to managers
- Check debug page WebSocket is connected
